# Senior Design: Spectrum Sensing

This repository is for the senior design spectrum-sensing project.

## Project goal
Develop and evaluate a spectrum-sensing workflow that can identify activity across a selected frequency range and report useful measurements for analysis.

## Planned workflow
1. Collect RF samples from the selected receiver/SDR.
2. Process the samples into frequency-domain data.
3. Estimate signal activity or power across the monitored band.
4. Apply a detection threshold or decision rule.
5. Display or log the sensing results for testing and evaluation.

## Suggested repository structure
- `src/` — spectrum-sensing and signal-processing code
- `tests/` — automated tests
- `docs/` — project documentation and design notes
- `data/` — sample or generated data (when appropriate)
